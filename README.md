# Pixara Home Assistant Add-ons

Custom Home Assistant OS add-ons.

## Included add-ons

- `stremio_csfd_catalogs` - Local Stremio addon for CSFD movie catalogs

## Add repository to Home Assistant

In Home Assistant, open the Add-on Store and add this repository URL.

## Repository structure

- `repository.yaml`
- `stremio_csfd_catalogs/config.yaml`
