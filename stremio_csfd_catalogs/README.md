# Stremio CSFD katalogy

Samostatny Home Assistant OS addon pro katalogy filmu z CSFD do Stremia.

Manifest po spusteni:

- `http://<HA-IP>:7010/manifest.json`

Addon umi:

- cist katalogy z CSFD HTML seznamu
- cachovat seznamy a detailni metadata
- vystavit `catalog` a `meta` endpointy pro Stremio
- testovat TMDB a Trakt pomocne integrace
