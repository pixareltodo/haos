# n8n Official for Home Assistant OS

This local add-on runs the official `docker.n8n.io/n8nio/n8n:stable` image.

It is designed for:

- direct access on port `5678`
- persistent n8n data in `/data/.n8n`
- simple environment-style configuration from the add-on options UI

See `DOCS.md` for install and configuration notes.
